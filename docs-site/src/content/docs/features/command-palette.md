---
title: Command palette
description: Run commands and jump to files or symbols from the keyboard.
---

Open the command palette with:

- `⌘⇧P` / `Ctrl+Shift+P`
- Also available via `⌘P` / `Ctrl+P` and `⌘K` / `Ctrl+K` for the quick-open style flows

From the palette you can:

- Run commands
- Jump to recent files
- Open project files
- Jump to symbols

If you are not sure where a feature lives in the UI, start here.
